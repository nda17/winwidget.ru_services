# AI-консультант: техническое досье legal/DPA и трансграничной передачи

Дата актуализации: 30.08.2026.

Документ фиксирует проверяемые технические факты и поля для внешней
юридической проверки. Он не является юридическим заключением, договором или
поданным уведомлением.

## Статус gate

Технические меры реализованы, но коммерческое масштабирование остаётся
заблокированным до завершения внешних действий:

1. В официальном реестре операторов Роскомнадзора по ИНН `2700019628` на
   30.08.2026 запись ООО ЮБС не найдена. Уполномоченному лицу необходимо
   проверить историю ранее поданных документов и, если подтверждения нет,
   подать уведомление по статье 22 Федерального закона № 152-ФЗ.
2. Отдельное уведомление о трансграничной передаче по статье 12 нельзя подать
   корректно до получения номера уведомления по статье 22, подтверждённой
   карты стран/получателей и письменных сведений Cloudflare о мерах защиты,
   сроках удаления и условиях прекращения обработки.
3. Проверенный production-аккаунт Cloudflare не является выделенным
   корпоративным аккаунтом ООО ЮБС и содержит зоны, не относящиеся к
   WinWidget. Само наличие доступа к dashboard не доказывает, что Main
   Agreement и DPA приняты уполномоченным лицом от имени ООО ЮБС. Нужны
   отдельное договорное подтверждение либо перенос WinWidget в корпоративную
   account boundary без затрагивания чужих зон.
4. Юрист должен подтвердить role matrix, основание 1095-дневного хранения
   минимальной квитанции согласия и выполнение требования первичной
   локализации данных граждан РФ.

Нельзя заменять эти действия обновлением политики на сайте. Юридически
значимые уведомления подписывает руководитель или иное уполномоченное лицо
ООО ЮБС, в том числе УКЭП при электронной подаче.

## Технические потоки

### Посетитель клиентского сайта или прямой страницы

1. Публичная конфигурация отдаёт визуальные настройки, ссылку на политику
   владельца, Sitekey Turnstile и неизменяемую редакцию согласия. Внутренняя
   инструкция владельца посетителю не раскрывается.
2. До явного согласия Turnstile не загружается. После согласия WinWidget
   сохраняет минимальную псевдонимизированную квитанцию.
3. Для создания сессии браузер передаёт Cloudflare Turnstile технические
   сигналы. Проверка Siteverify дополнительно получает response token,
   IP-адрес посетителя, action, hostname и idempotency key.
4. Workers AI получает текущий вопрос, до 12 последних сообщений контекста,
   имя AI-оператора и бизнес-инструкцию владельца. При grounding-проверке
   второй вызов также получает кандидат ответа и точный фрагмент основания.

### Тестовый чат владельца

Authenticated endpoint тестирования передаёт Workers AI сохранённую
бизнес-инструкцию, тестовый вопрос и до 12 сообщений. Это отдельный поток
данных пользователя кабинета, сотрудника, ADMIN или DEV. Endpoint принимает
запрос только с явным `aiCloudflareDisclosureAcknowledged: true`; Turnstile в
этом потоке не используется.

### Минимизация и хранение WinWidget

- вопрос, история и ответ не записываются в PostgreSQL и прикладные логи;
- результат идентичного запроса может находиться в памяти процесса до 5 минут;
- session token действует 10 минут, consent proof — 15 минут;
- неподтверждённая квитанция удаляется после истечения proof window;
- подтверждённая квитанция без переписки хранится 1095 дней;
- исходные IP, User-Agent и session ID в квитанции заменяются HMAC scopes;
- AI Gateway получает `cf-aig-collect-log: false`, поэтому для вызова не
  создаётся AI Gateway log entry, включая payload и metadata. Это не означает
  отсутствие всей operational/security processing внутри Workers AI или
  Turnstile.
- В dashboard gateway `winwidget-ai-consultant` на 30.08.2026 account-level
  `Collect Logs` и cache выключены; это дополняет, но не заменяет обязательные
  per-request заголовки приложения.

## Предварительная role matrix

| Сценарий                           | Владелец цели                                       | WinWidget / ООО ЮБС                                       | Cloudflare                                               |
| ---------------------------------- | --------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------- |
| AI на сайте клиента                | Владелец сайта — предполагаемый operator/controller | Предполагаемый обработчик по письменному поручению        | Workers AI — downstream processor/subprocessor           |
| AI на ресурсе WinWidget            | ООО ЮБС — предполагаемый operator/controller        | Operator/controller                                       | Workers AI — processor                                   |
| Turnstile для защиты сайта         | Владелец цели проверки                              | Processor либо operator для собственного сайта            | Processor для security purpose                           |
| Улучшение bot detection по Signals | Cloudflare определяет отдельную цель                | Передающая сторона по применимому договору                | Самостоятельный controller по Turnstile Privacy Addendum |
| Тестовый чат кабинета              | ООО ЮБС определяет QA purpose                       | Operator/controller либо processor по договору с клиентом | Workers AI — processor                                   |

Финальную квалификацию утверждает юрист вместе с договором с клиентом. В
клиентском DPA должны быть цель, состав данных, операции, безопасность,
конфиденциальность, subprocessors, помощь по правам субъектов, удаление,
incident notification и audit evidence.

## Cloudflare evidence

- Публичная Cloudflare Customer DPA: версия 6.4, действует с 03.04.2026:
  <https://www.cloudflare.com/cloudflare-customer-dpa/>.
- Self-Serve Subscription Agreement включает DPA по ссылке, однако необходимо
  доказать применимый agreement и полномочия принявшего его лица:
  <https://www.cloudflare.com/terms/>.
- Workers AI заявляет, что Customer Content не используется для обучения без
  явного согласия и persistent storage возникает только при отдельном
  подключении storage-сервисов:
  <https://developers.cloudflare.com/workers-ai/platform/data-usage/>.
- Turnstile Privacy Addendum описывает security signals и двойную роль
  Cloudflare:
  <https://www.cloudflare.com/turnstile-privacy-policy/>.
- Публичный список subprocessors является исходной информацией, но не
  подтверждает точный runtime routing конкретного аккаунта:
  <https://www.cloudflare.com/gdpr/subprocessors/cloudflare-services/>.

До уведомления необходимо получить от Cloudflare письменное подтверждение
фактически применимых contracting entity, Workers AI/AI Gateway/Turnstile
subprocessors, стран, retention/deletion, backup/telemetry и мер защиты.
